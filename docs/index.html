优先级：列表从上到下，越上越先命中 · 可用↑↓调整
为每个分类配置关键字（逗号分隔），按当前匹配模式命中分类。已内置 4 类，可新增 / 编辑 / 删除，支持 ↑↓ 调整顺序。

分类说明

• 按列表顺序匹配，命中即归类，未命中归“未分类”
• 关键字不区分大小写
• 语料仅在结果中关联展示
